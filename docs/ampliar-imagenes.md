# Ampliar imágenes con Topaz Gigapixel

Úsalo antes de mandar a Gelato cualquier imagen que no llegue al tamaño pedido: fotos de clientes («Sube tu foto»), ilustraciones de plantilla o tus propias obras.

## Píxeles que necesita cada tamaño (300 ppp)

| Tamaño | Píxeles (ancho × alto) |
|---|---|
| A4 | 2.480 × 3.508 |
| A3 | 3.508 × 4.961 |
| A2 | 4.961 × 7.016 |
| 50×70 | 5.906 × 8.268 |
| A1 | 7.016 × 9.933 |
| XL 60×90 | 7.087 × 10.630 |
| Lienzo 20×25 | 2.362 × 2.953 |
| Lienzo 30×40 | 3.543 × 4.724 |
| Lienzo 45×60 | 5.315 × 7.087 |
| Lienzo 60×80 | 7.087 × 9.449 |

Lienzo: Gelato puede pedir un margen extra para el borde que se dobla en el bastidor. Mira en su ficha el tamaño exacto del archivo [CONFIRMAR].

## Pasos

1. Abre la imagen en Topaz Gigapixel.
2. En tamaño de salida elige **ancho/alto en píxeles** y pon el de la tabla (o algo más).
3. Modelo:
   - **Foto real (personas, mascotas):** el modelo de alta fidelidad / estándar, con **recuperación de caras** activada si hay caras.
   - **Ilustración, obra plana, plantilla:** el modelo para arte / CG.
   - Si la imagen es muy pequeña o está borrosa: prueba el modelo para baja resolución o el generativo (Recover).
4. Mira el resultado al **100 % de zoom**: ojos, pelo, bordes y texto (el nombre en las plantillas). No debe verse «de plástico» ni con detalles inventados raros.
5. Exporta en **PNG** o **JPG calidad máxima**, perfil de color **sRGB**.
6. Sube ese archivo a Gelato.

Los nombres exactos de los modelos cambian entre versiones de Topaz: elige el que más se parezca [CONFIRMAR en tu versión].
