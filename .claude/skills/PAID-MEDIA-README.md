# Skills de Claude para Media Buyers

51 skills reutilizables para toda tu cuenta publicitaria, organizadas en 7 carpetas.

## Cómo usarlas

- En Claude (chat): adjunta el .md de la skill junto a tus datos (export, captura, URL) y pide «aplica esta skill».
- En un Proyecto de Claude: sube la carpeta completa al conocimiento del proyecto.
- En Claude Code: copia la carpeta a tu repo y referencia la skill por nombre.

Cada archivo tiene frontmatter (name, description), proceso paso a paso, umbrales y formato de salida.
Los umbrales son punto de partida: calíbralos con el histórico de cada cuenta.
